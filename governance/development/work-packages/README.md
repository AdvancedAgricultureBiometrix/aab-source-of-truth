# Development work packages

This folder holds AAB's development work packages, under the parallel development protocol (`governance/development/PARALLEL-DEVELOPMENT-PROTOCOL-2026-10-02.md`).

**No work package exists yet.**

- **Each work package has its own folder:** `DWP-NNN-<short-name>/`, holding its `WORK-PACKAGE.md` (protocol, section 4) and its `HANDOVER.md` (section 5).
- **Identifiers are `DWP-NNN`.** They are never `WPnn`, which belongs to the Phase-2 work packages in `governance/phase-2/`.
- **Every work package is listed in the coordination register,** `governance/development/COORDINATION-REGISTER.md`, which is created with the first work package (section 8).
- **A work package's folder is changed only by its owner,** on its own branch, after its `WORK-PACKAGE.md` is merged to `main`.
