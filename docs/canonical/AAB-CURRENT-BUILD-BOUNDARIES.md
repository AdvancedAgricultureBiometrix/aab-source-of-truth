# AAB Current Build Boundaries

Status: Canonical present-state record
Environment: Western Australia private build-and-validation workspace

## What exists now

- One private Supabase environment supports the current build-and-validation work.
- Western Australia is the controlled jurisdiction used to progress toward the real AAB scientific system.
- The country discovery interface can demonstrate reusable jurisdiction selection, scanning, evidence cards, governance boundaries and country-specific presentation.
- Thailand, Vietnam, the Philippines and China are demonstration and discovery-engine test profiles within this private environment. They are not onboarded sovereign tenants.
- Country discovery findings remain country-scoped and quarantined.
- A governed owner-only Country Resource Investigation operation can preserve evidence, observations and measurement states.
- Scientific approval, experimental ingredient projection, ingredient activation, Brain admission, formulation selection and trial use remain separate and locked unless explicitly built and authorised.
- The current build tests the path from country discovery toward scientific investigation; it does not constitute a completed sovereign deployment.

## What does not yet exist

- A production tenancy for an onboarded country.
- Proven country-controlled encryption-key custody or air-gapped deployment.
- Completed multi-institution domestic collaboration.
- Operational external peer-review packages.
- A Governed Scientific Exchange.
- Federated cross-country scientific learning.
- Autonomous creation or activation of ingredients.
- Autonomous scientific approval or formulation authority.

## Operational country rule

When a real country onboards, it must receive a new empty and isolated environment. Demonstration findings, users, invitations, evidence, scientific memory and configuration must not be copied from the current build-and-validation database unless a separately governed migration explicitly authorises each permitted item.

## Required wording discipline

- Say **planned**, **designed** or **required** for capabilities not yet implemented.
- Do not claim absolute security, complete de-identification or guaranteed sovereignty.
- Do not describe a source-discovery signal as a verified material, recoverable quantity, safe ingredient or proven benefit.
- Do not describe a candidate as available to an AAB Brain or formulation system unless its exact governed gates have been completed.
